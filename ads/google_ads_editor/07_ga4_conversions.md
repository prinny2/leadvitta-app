# GA4 to Google Ads Conversions Setup

Generated by `npm run ads:generate`. GA4 property: `G-223KR63TS8`

## Step 1: Link GA4 Property to Google Ads

1. In Google Ads, go to Tools and settings > Measurement > Conversions.
2. Click Google Analytics 4.
3. Link property `G-223KR63TS8` (LeadBellus).
4. Enable 'Import site metrics' and 'Import conversions'.

## Step 2: Import / Create Conversions from GA4

Recommended conversions to bring in (create as 'Import from Google Analytics 4' or use the link):

- **sign_up** — Category: Sign-up — Include in: Conversions
- **begin_checkout** — Category: Begin checkout — Include in: Conversions
- **purchase** — Category: Purchase — Include in: Conversions (use value from GA4)
- **generate** — Category: Generate response — Include in: All

## Step 3: Attribution & Settings (Editor / Web UI)

- Attribution model: Data-driven (recommended) or Last click (non-direct).
- Conversion window: 30 days (or match your sales cycle).
- Count: Every (for sign_up / begin_checkout) or One (for purchase if needed).
- Make 'purchase' the primary conversion for bidding.

## Step 4: Use in Bidding & Editor

After import:
- In the imported campaign, set Bid strategy to 'Maximize conversions' or 'Target CPA' using the imported purchase/sign_up.
- In Editor, after importing keywords/ads, verify the conversion column shows the GA4 ones.
- Use automated rules that reference conversions (see 06_automation_rules.md).

Safety: Keep campaign paused until at least one full conversion cycle is verified in both GA4 and Google Ads reports.
